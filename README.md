## 🛠️ Repo นี้ถูกสร้างอย่างไร

1. ส่งออกเอกสารแอปจาก AppSheet (ผู้ใช้ทำผ่าน AppSheet Editor) → ได้ไฟล์ PDF 1,946 หน้า
2. ดึงข้อความจาก PDF ด้วยเอนจินที่รองรับภาษาไทย (ตำแหน่ง glyph ถูกใช้จำแนกการตัดบรรทัดจริงกับการ wrap กลางคำ) แล้ว parse เป็นโครงสร้าง JSON — ตรวจสอบความครบถ้วนกับตัวเลขสรุปของเอกสาร: ตาราง 90/90 คอลัมน์ 2,304/2,304 Views 115/115 Actions 214/214 Slices 8/8 Format Rules 11/11 และ JSON ทุกก้อน parse ผ่าน 100%
3. ปกปิดอีเมลพนักงาน 14 รายการและเบอร์โทร 2 หมายเลข (ใน Markdown ใช้ placeholder, ใน PDF ใช้แถบปกปิด)
4. จัดโครงสร้างเป็นโฟลเดอร์รายตาราง + เอกสารกลาง แล้วสร้างไฟล์สำหรับ AI ทั้ง 5 ไฟล์นี้
