## 📚 รายละเอียดปัญหาและวิธีแก้

### 1. 🟡 ตารางไม่มี Security Filter (ทุกคนโหลดทุกแถว)

**ตำแหน่ง:** ตารางทั้งตาราง  

**ทำไมต้องแก้:** ไม่มี Security Filter หมายความว่าทุกผู้ใช้จะโหลดข้อมูลทั้งตารางมาที่เครื่องตอน sync สำหรับตารางที่ใช้ร่วมกันทั้งทีมถือเป็นเรื่องปกติ แต่ถ้าแถวเยอะมากจะทำให้ sync ช้าและกินเน็ตมือถือ และยังไม่มีชั้นป้องกันถ้าวันหนึ่งมีการเพิ่มคอลัมน์อ่อนไหวในตารางนี้

**วิธีแก้ใน AppSheet Editor:**

1. ถ้าตารางนี้ทุกคนในทีมควรเห็นหมด — ปล่อยได้ แต่จดไว้ว่า "ห้ามเพิ่มข้อมูลส่วนบุคคลภายหลัง"
2. ถ้าอยากให้เห็นเฉพาะของตัวเอง ทำตามแบบที่แอปใช้อยู่: Data > ตารางนี้ > Security Filter ใส่ `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())`
3. ถ้าตารางเป็นตารางอ่านอย่างเดียวทั้งทีม (เช่น ตารางราคา) การไม่มี filter ถือว่าเหมาะสม

### 2. 🟠 สูตรฝังตัวเลขคงที่ (ราคา/โบนัส/เกณฑ์) ไว้ข้างใน

**ตำแหน่ง:** คอลัมน์ `เดือน`  
**ตัวเลขที่ฝังอยู่:** 2500  

**ทำไมต้องแก้:** เมื่อราคาหรือเกณฑ์เปลี่ยน ต้องมาหาว่าสูตรไหนฝังเลขไว้บ้างแล้วแก้ทีละจุด เสี่ยงแก้ไม่ครบและแก้สูตรพลาดจนระบบคิดเงินผิด วิธีที่ยืดหยุ่นกว่าคือเก็บค่าเหล่านี้ไว้ในตารางตั้งค่า (เช่น Price_Table ที่แอปมีอยู่แล้ว) แล้วให้สูตรไปอ่านจากตาราง

**สูตร/ค่าปัจจุบัน:**
```
IF( ISBLANK([วันที่เข้ารับ]), "", CONCATENATE( YEAR([วันที่เข้ารับ]) - IF(YEAR([วันที่เข้ารับ]) > 2500, 543, 0), "-", TEXT([วันที่เข้ารับ],"MM") ) )
```

**วิธีแก้ใน AppSheet Editor:**

1. เพิ่มแถวค่าคงที่ลงตารางตั้งค่า/ตารางราคาที่มีอยู่ (เช่น Price_Table, PriceOverride) ให้ครบทุกเงื่อนไข
2. แก้สูตรให้ไป LOOKUP ค่าจากตารางแทนเลขที่ฝังไว้ เช่น `LOOKUP([ชื่องาน], "Price_Table", "งาน", "ราคา")`
3. หมายเหตุ: ถ้าเลขที่ฝังเป็นการแปลงหน่วย เช่น `* 1000` แปลงกิโลเมตรเป็นเมตร ไม่ต้องย้าย — นั่นคือคณิตศาสตร์ ไม่ใช่ค่าธุรกิจ
