## 📚 รายละเอียดปัญหาและวิธีแก้

### 1. 🟠 คอลัมน์เงินใช้ชนิด Number ควรใช้ Price

**ตำแหน่ง:** คอลัมน์ `ราคาตามบิล`  

**ทำไมต้องแก้:** ชนิด Number ไม่แสดงสัญลักษณ์เงินบาทและคุมจำนวนทศนิยมไม่ตรง ทำให้หน้าจอโชว์เลขดิบ ๆ และผู้ใช้อาจกรอกค่าที่ไม่ใช่จำนวนเงินได้ การใช้ Price จะแสดง ฿ นำหน้าและคุมทศนิยมให้อัตโนมัติ

**วิธีแก้ใน AppSheet Editor:**

1. เปิด Data > ตารางนี้ > คอลัมน์ดังกล่าว
2. เปลี่ยน Type เป็น **Price** แล้วตรวจว่า Currency Symbol เป็น **฿**
3. ตรวจสูตร/View ที่อ้างคอลัมน์นี้ — ค่าใน Google Sheets ไม่เปลี่ยน เปลี่ยนแค่วิธีแสดงผล

### 2. 🟠 สูตรใช้ SELECT() ซึ่งสแกนทั้งตารางที่อ้างถึง

**ตำแหน่ง:** คอลัมน์ `ราคาตามระยะทาง`  

**ทำไมต้องแก้:** SELECT() ต้องไล่อ่านทุกแถวของตารางปลายทางทุกครั้งที่คำนวณ ยิ่งเป็น Virtual Column จะยิ่งคำนวณซ้ำบ่อย เมื่อข้อมูลโตขึ้นเป็นพัน ๆ แถว แอปจะเริ่มช้าชัดเจน โดยเฉพาะหน้าจอที่เปิดทีเดียวแสดงหลายแถว (deck/table)

**สูตร/ค่าปัจจุบัน:**
```
ANY( SELECT( Price_Table[Price], AND( IN( [_THISROW].[ชื่องาน], SPLIT([ชื่องาน], ",") ), [เรทน้ำมัน_Minimum] <= [_THISROW]. [เรทดีเซล], [เรทน้ำมัน_Maximum] >= [_THISROW].[เรทดีเซล], [ระยะทาง_Minimum] <= [_THISROW].[ระยะทางที่วิ่ง (KM)], [ระยะทาง_Maximum] >= [_THISROW].[ระยะทางที่วิ่ง (KM)] ) ) )
```

**วิธีแก้ใน AppSheet Editor:**

1. ถ้าผลลัพธ์คือค่าเดียว ใช้ **LOOKUP()** แทน (เร็วกว่าเพราะหยุดเมื่อเจอ)
2. ถ้าอ้างแถวผ่านคอลัมน์ Ref อยู่แล้ว ใช้การเขียนแบบจุด `[RefColumn].[FieldName]` แทน SELECT ทั้งชุด
3. ทำให้เงื่อนไข SELECT แคบลง เช่น กรองด้วยวันที่/สถานะก่อน แล้วค่อยคำนวณ
4. ถ้าค่านี้ไม่จำเป็นต้องเรียลไทม์ พิจารณาเปลี่ยนเป็นคอลัมน์จริงที่ Action/Bot คำนวณเก็บให้ (ลดภาระตอน sync)

### 4. 🟠 สูตรฝังตัวเลขคงที่ (ราคา/โบนัส/เกณฑ์) ไว้ข้างใน

**ตำแหน่ง:** คอลัมน์ `ราคาเพิ่ม`  
**ตัวเลขที่ฝังอยู่:** 1200, 2400, 500  

**ทำไมต้องแก้:** เมื่อราคาหรือเกณฑ์เปลี่ยน ต้องมาหาว่าสูตรไหนฝังเลขไว้บ้างแล้วแก้ทีละจุด เสี่ยงแก้ไม่ครบและแก้สูตรพลาดจนระบบคิดเงินผิด วิธีที่ยืดหยุ่นกว่าคือเก็บค่าเหล่านี้ไว้ในตารางตั้งค่า (เช่น Price_Table ที่แอปมีอยู่แล้ว) แล้วให้สูตรไปอ่านจากตาราง

**สูตร/ค่าปัจจุบัน:**
```
IF([เลือกเพิ่มเติม] = "เพิ่มแรงงาน1คน",500, IF([เลือกเพิ่มเติม] = "จองรถก่อน14.00+แรงงาน1คน",1200, IF([เลือกเพิ่มเติม] = "งานMeSpace+แพ็คสินค้า",2400,0)))
```

**วิธีแก้ใน AppSheet Editor:**

1. เพิ่มแถวค่าคงที่ลงตารางตั้งค่า/ตารางราคาที่มีอยู่ (เช่น Price_Table, PriceOverride) ให้ครบทุกเงื่อนไข
2. แก้สูตรให้ไป LOOKUP ค่าจากตารางแทนเลขที่ฝังไว้ เช่น `LOOKUP([ชื่องาน], "Price_Table", "งาน", "ราคา")`
3. หมายเหตุ: ถ้าเลขที่ฝังเป็นการแปลงหน่วย เช่น `* 1000` แปลงกิโลเมตรเป็นเมตร ไม่ต้องย้าย — นั่นคือคณิตศาสตร์ ไม่ใช่ค่าธุรกิจ
