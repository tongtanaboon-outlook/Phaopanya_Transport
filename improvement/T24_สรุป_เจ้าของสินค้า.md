## 📚 รายละเอียดปัญหาและวิธีแก้

### 1. 🔴 ตารางเก็บข้อมูลอ่อนไหว (ราคา/ข้อมูลพนักงาน) แต่ไม่มี Security Filter

**ตำแหน่ง:** ตารางทั้งตาราง  

**ทำไมต้องแก้:** ตารางนี้มีคอลัมน์ที่บ่งบอกเงินหรือตัวตนของพนักงาน แต่ทุกผู้ใช้โหลดทุกแถวได้หมด แปลว่าพนักงานคนหนึ่งเปิดดูยอด/ราคาของเพื่อนร่วมทีมได้ ทั้งเรื่องความเป็นส่วนตัวและความขัดแย้งในทีม แอปมีแบบแผนสำเร็จอยู่แล้ว 7 ตาราง แค่นำมาใช้เพิ่ม

**วิธีแก้ใน AppSheet Editor:**

1. เปิด Data > ตารางนี้ > **Security Filter** ใส่สูตรตามมาตรฐานที่แอปใช้ เช่น `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())`
2. ถ้าคอลัมน์อีเมลเจ้าของงานมีชื่อต่างกัน ให้เปลี่ยน `[Email พนักงาน]` เป็นชื่อคอลัมน์จริงของตารางนี้
3. ทดสอบด้วยบัญชี USER ปกติ 1 บัญชีว่าเห็นเฉพาะแถวของตัวเอง และ ADMIN เห็นหมด
4. ผลพลอยได้: แต่ละเครื่องโหลดเฉพาะแถวของตัวเอง sync เร็วขึ้นชัดเจน

### 2. 🟠 สูตรใช้ FILTER() ซึ่งสแกนทั้งตารางที่อ้างถึง

**ตำแหน่ง:** คอลัมน์ `รายการ_ทั้งหมด`  

**ทำไมต้องแก้:** FILTER() ทำงานเหมือน SELECT() คือไล่ทุกแถว ใช้กับ Virtual Column จะเป็นตัวถ่วงประสิทธิภาพหลักของแอปเมื่อข้อมูลโต

**สูตร/ค่าปัจจุบัน:**
```
FILTER( "ตารางงานประจำวัน", AND( [ชื่อเจ้าของสินค้า] = [_THISROW].[SoldToName], [Plan Delivery] = [_THISROW]. [PlanDelivery] ) )
```

**วิธีแก้ใน AppSheet Editor:**

1. ถ้าจุดประสงค์คือ "รายการที่อ้างถึงแถวนี้" ให้ใช้ **REF_ROWS()** ที่ใช้คอลัมน์ Ref โดยตรง (เร็วกว่าชัดเจน)
2. จำกัดขอบเขตเงื่อนไขให้แคบที่สุด และหลีกเลี่ยงการเรียก FILTER ซ้อนในลูป
3. ค่าที่ไม่ต้องเรียลไทม์ ให้ Bot คำนวณแล้วเขียนเก็บเป็นคอลัมน์จริง

### 5. 🟠 สูตรใช้ SELECT() ซึ่งสแกนทั้งตารางที่อ้างถึง

**ตำแหน่ง:** คอลัมน์ `จำนวน_สแกนแล้ว`  

**ทำไมต้องแก้:** SELECT() ต้องไล่อ่านทุกแถวของตารางปลายทางทุกครั้งที่คำนวณ ยิ่งเป็น Virtual Column จะยิ่งคำนวณซ้ำบ่อย เมื่อข้อมูลโตขึ้นเป็นพัน ๆ แถว แอปจะเริ่มช้าชัดเจน โดยเฉพาะหน้าจอที่เปิดทีเดียวแสดงหลายแถว (deck/table)

**สูตร/ค่าปัจจุบัน:**
```
COUNT( UNIQUE( SELECT( ตารางงานประจำวัน[Invoice No], AND( [ชื่อเจ้าของสินค้า] = [_THISROW].[SoldToName], [Plan Delivery] = [_THISROW].[PlanDelivery], [ScanStatus] = "สแกนรับ แล้ว" ) ) ) )
```

**วิธีแก้ใน AppSheet Editor:**

1. ถ้าผลลัพธ์คือค่าเดียว ใช้ **LOOKUP()** แทน (เร็วกว่าเพราะหยุดเมื่อเจอ)
2. ถ้าอ้างแถวผ่านคอลัมน์ Ref อยู่แล้ว ใช้การเขียนแบบจุด `[RefColumn].[FieldName]` แทน SELECT ทั้งชุด
3. ทำให้เงื่อนไข SELECT แคบลง เช่น กรองด้วยวันที่/สถานะก่อน แล้วค่อยคำนวณ
4. ถ้าค่านี้ไม่จำเป็นต้องเรียลไทม์ พิจารณาเปลี่ยนเป็นคอลัมน์จริงที่ Action/Bot คำนวณเก็บให้ (ลดภาระตอน sync)

### 6. 🟠 เก็บจำนวนเงินเป็นชนิด Text

**ตำแหน่ง:** คอลัมน์ `สรุปยอด`  

**ทำไมต้องแก้:** ข้อความ (Text) รวมยอด เรียงลำดับ หรือเทียบมาก-น้อยไม่ได้แบบตัวเลข สูตรอย่าง SUM()/TOTAL() จะพังหรือให้ผลผิด และถ้ามีตัวอักษรปนเข้าไป (เช่น "200 บาท") จะยิ่งแก้ยากภายหลัง แนะนำแก้ตั้งแต่ยังมีข้อมูลไม่มาก

**สูตร/ค่าปัจจุบัน:**
```
IF( [จำนวน_E-POD_ทั้งหมด] > 0, " 𝐄 ─ 🅿️🅾️𝐃🟰 " & [จำนวน_E-POD_ทั้งหมด], " 📋🟰 " & [จำนวน_ทั้งหมด] & " ✅🟰 " & [จำนวน_สแกนแล้ว] & " ⏳🟰 " & [จำนวน_รอสแกน] )
```

**วิธีแก้ใน AppSheet Editor:**

1. เปิด Data > ตารางนี้ > คอลัมน์ดังกล่าว เปลี่ยน Type เป็น **Price** (หรือ Decimal ถ้าไม่ต้องการ ฿)
2. เปิด Google Sheets ล้างค่าที่มีตัวอักษรปน ให้เหลือแต่ตัวเลข (เช่น ลบคำว่า "บาท" ออก)
3. ถ้าคอลัมน์นี้ต้องเก็บข้อความปนจริง ๆ ให้สร้างคอลัมน์ตัวเลขแยกต่างหากไว้คำนวณ ส่วน Text ไว้แสดง
