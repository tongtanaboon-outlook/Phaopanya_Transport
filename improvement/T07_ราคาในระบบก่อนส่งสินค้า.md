## 📚 รายละเอียดปัญหาและวิธีแก้

### 1. 🔴 ตารางเก็บข้อมูลอ่อนไหว (ราคา/ข้อมูลพนักงาน) แต่ไม่มี Security Filter

**ตำแหน่ง:** ตารางทั้งตาราง  

**ทำไมต้องแก้:** ตารางนี้มีคอลัมน์ที่บ่งบอกเงินหรือตัวตนของพนักงาน แต่ทุกผู้ใช้โหลดทุกแถวได้หมด แปลว่าพนักงานคนหนึ่งเปิดดูยอด/ราคาของเพื่อนร่วมทีมได้ ทั้งเรื่องความเป็นส่วนตัวและความขัดแย้งในทีม แอปมีแบบแผนสำเร็จอยู่แล้ว 7 ตาราง แค่นำมาใช้เพิ่ม

**วิธีแก้ใน AppSheet Editor:**

1. เปิด Data > ตารางนี้ > **Security Filter** ใส่สูตรตามมาตรฐานที่แอปใช้ เช่น `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())`
2. ถ้าคอลัมน์อีเมลเจ้าของงานมีชื่อต่างกัน ให้เปลี่ยน `[Email พนักงาน]` เป็นชื่อคอลัมน์จริงของตารางนี้
3. ทดสอบด้วยบัญชี USER ปกติ 1 บัญชีว่าเห็นเฉพาะแถวของตัวเอง และ ADMIN เห็นหมด
4. ผลพลอยได้: แต่ละเครื่องโหลดเฉพาะแถวของตัวเอง sync เร็วขึ้นชัดเจน

### 2. 🟠 คอลัมน์ Key ให้ผู้ใช้กรอกเอง โดยไม่มีสูตร/ค่าเริ่มต้น

**ตำแหน่ง:** คอลัมน์ `Shipment No`  

**ทำไมต้องแก้:** คีย์คือหมายเลขประจำแถวที่ระบบใช้เชื่อมโยงทุกอย่าง ถ้าให้พิมพ์เองจะเสี่ยงซ้ำ (AppSheet จะเตือนตอนบันทึก) หรือเว้นว่าง ทำให้ความสัมพันธ์ Ref ชี้พลาด เว้นแต่คีย์นี้มีความหมายธุรกิจอยู่แล้ว เช่น เลขที่ Invoice จริง

**วิธีแก้ใน AppSheet Editor:**

1. ถ้าคีย์เป็นค่าที่มีความหมายอยู่แล้ว (เลข Invoice, รหัสงานจากระบบอื่น) — ใช้แบบนี้ได้ แต่ควรเปิด Required
2. ถ้าคีย์เป็นแค่หมายเลขเทคนิค: ตั้ง Initial Value เป็น **UNIQUEID()** เพื่อให้ระบบสร้างให้เอง ซ้ำไม่ได้แน่นอน
3. ถ้าอยากได้รหัสแบบอ่านรู้เรื่อง เช่น วันที่+รันนิ่ง ให้ใช้ App Formula `CONCATENATE(TEXT(TODAY(),"yymmdd"),"-",UNIQUEID())`

### 3. 🟠 สูตรฝังตัวเลขคงที่ (ราคา/โบนัส/เกณฑ์) ไว้ข้างใน

**ตำแหน่ง:** คอลัมน์ `เดือน`  
**ตัวเลขที่ฝังอยู่:** 2500  

**ทำไมต้องแก้:** เมื่อราคาหรือเกณฑ์เปลี่ยน ต้องมาหาว่าสูตรไหนฝังเลขไว้บ้างแล้วแก้ทีละจุด เสี่ยงแก้ไม่ครบและแก้สูตรพลาดจนระบบคิดเงินผิด วิธีที่ยืดหยุ่นกว่าคือเก็บค่าเหล่านี้ไว้ในตารางตั้งค่า (เช่น Price_Table ที่แอปมีอยู่แล้ว) แล้วให้สูตรไปอ่านจากตาราง

**สูตร/ค่าปัจจุบัน:**
```
IF( ISBLANK([วันที่ส่งสินค้า]), "", CONCATENATE( YEAR([วันที่ส่งสินค้า]) - IF(YEAR([วันที่ส่งสินค้า]) > 2500, 543, 0), "-", TEXT([วันที่ส่งสินค้า], "MM") ) )
```

**วิธีแก้ใน AppSheet Editor:**

1. เพิ่มแถวค่าคงที่ลงตารางตั้งค่า/ตารางราคาที่มีอยู่ (เช่น Price_Table, PriceOverride) ให้ครบทุกเงื่อนไข
2. แก้สูตรให้ไป LOOKUP ค่าจากตารางแทนเลขที่ฝังไว้ เช่น `LOOKUP([ชื่องาน], "Price_Table", "งาน", "ราคา")`
3. หมายเหตุ: ถ้าเลขที่ฝังเป็นการแปลงหน่วย เช่น `* 1000` แปลงกิโลเมตรเป็นเมตร ไม่ต้องย้าย — นั่นคือคณิตศาสตร์ ไม่ใช่ค่าธุรกิจ
