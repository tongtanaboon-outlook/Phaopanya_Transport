## 📚 รายละเอียดปัญหาและวิธีแก้

### 1. 🟡 ตารางไม่มี Security Filter (ทุกคนโหลดทุกแถว)

**ตำแหน่ง:** ตารางทั้งตาราง  

**ทำไมต้องแก้:** ไม่มี Security Filter หมายความว่าทุกผู้ใช้จะโหลดข้อมูลทั้งตารางมาที่เครื่องตอน sync สำหรับตารางที่ใช้ร่วมกันทั้งทีมถือเป็นเรื่องปกติ แต่ถ้าแถวเยอะมากจะทำให้ sync ช้าและกินเน็ตมือถือ และยังไม่มีชั้นป้องกันถ้าวันหนึ่งมีการเพิ่มคอลัมน์อ่อนไหวในตารางนี้

**วิธีแก้ใน AppSheet Editor:**

1. ถ้าตารางนี้ทุกคนในทีมควรเห็นหมด — ปล่อยได้ แต่จดไว้ว่า "ห้ามเพิ่มข้อมูลส่วนบุคคลภายหลัง"
2. ถ้าอยากให้เห็นเฉพาะของตัวเอง ทำตามแบบที่แอปใช้อยู่: Data > ตารางนี้ > Security Filter ใส่ `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())`
3. ถ้าตารางเป็นตารางอ่านอย่างเดียวทั้งทีม (เช่น ตารางราคา) การไม่มี filter ถือว่าเหมาะสม

### 2. 🟠 คอลัมน์เงินตั้งสัญลักษณ์เป็นดอลลาร์ ($) แทนที่จะเป็นบาท

**ตำแหน่ง:** คอลัมน์ `ราคารวม`  

**ทำไมต้องแก้:** หน้าจอและรายงานจะแสดงหน้าเลขด้วย $ ทั้งที่เป็นเงินบาท ทำให้พนักงานสับสนหรือเข้าใจผิดเรื่องจำนวนเงิน เป็นจุดเล็กแก้ง่ายแต่กระทบความเชื่อมั่นในข้อมูล

**สูตร/ค่าปัจจุบัน:**
```
SUM(SELECT(ข้อมูลการวางบิล[ราคา], AND([ชื่องาน]= [_THISROW].[ชื่องาน],[วันที่] >= [_THISROW].[Startdate], [วันที่] <= [_THISROW].[Enddate])))
```

**วิธีแก้ใน AppSheet Editor:**

1. เปิด Data > ตารางนี้ > คอลัมน์ดังกล่าว > Type Details
2. เปลี่ยน **Currency Symbol** เป็น **฿**

### 4. 🟠 สูตรใช้ FILTER() ซึ่งสแกนทั้งตารางที่อ้างถึง

**ตำแหน่ง:** คอลัมน์ `ปริ๊นใบวางบิล`  

**ทำไมต้องแก้:** FILTER() ทำงานเหมือน SELECT() คือไล่ทุกแถว ใช้กับ Virtual Column จะเป็นตัวถ่วงประสิทธิภาพหลักของแอปเมื่อข้อมูลโต

**สูตร/ค่าปัจจุบัน:**
```
FILTER("ข้อมูลการวางบิล",(AND([ชื่องาน]=[_THISROW].[ชื่องาน], [วันที่]>=[_THISROW].[StartDate],[วันที่]<=[_THISROW]. [EndDate])))
```

**วิธีแก้ใน AppSheet Editor:**

1. ถ้าจุดประสงค์คือ "รายการที่อ้างถึงแถวนี้" ให้ใช้ **REF_ROWS()** ที่ใช้คอลัมน์ Ref โดยตรง (เร็วกว่าชัดเจน)
2. จำกัดขอบเขตเงื่อนไขให้แคบที่สุด และหลีกเลี่ยงการเรียก FILTER ซ้อนในลูป
3. ค่าที่ไม่ต้องเรียลไทม์ ให้ Bot คำนวณแล้วเขียนเก็บเป็นคอลัมน์จริง

### 7. 🟠 สูตรใช้ SELECT() ซึ่งสแกนทั้งตารางที่อ้างถึง

**ตำแหน่ง:** คอลัมน์ `ราคารวม_ทำเบิกส่วนต่างScgวังน้อย`  

**ทำไมต้องแก้:** SELECT() ต้องไล่อ่านทุกแถวของตารางปลายทางทุกครั้งที่คำนวณ ยิ่งเป็น Virtual Column จะยิ่งคำนวณซ้ำบ่อย เมื่อข้อมูลโตขึ้นเป็นพัน ๆ แถว แอปจะเริ่มช้าชัดเจน โดยเฉพาะหน้าจอที่เปิดทีเดียวแสดงหลายแถว (deck/table)

**สูตร/ค่าปัจจุบัน:**
```
SUM(SELECT( ทำเบิกส่วนต่างScgวังน้อย[ขออนุมัติเบิกค่าขนส่งส่วนเพิ่ม], AND(ISNOTBLANK([วันที่ส่งสินค้า]), [วันที่ส่งสินค้า] >= [_THISROW].[StartDate], [วันที่ส่งสินค้า] <= [_THISROW]. [EndDate], [สถานะ] = "ผ่านการตรวจสอบ" ) ))
```

**วิธีแก้ใน AppSheet Editor:**

1. ถ้าผลลัพธ์คือค่าเดียว ใช้ **LOOKUP()** แทน (เร็วกว่าเพราะหยุดเมื่อเจอ)
2. ถ้าอ้างแถวผ่านคอลัมน์ Ref อยู่แล้ว ใช้การเขียนแบบจุด `[RefColumn].[FieldName]` แทน SELECT ทั้งชุด
3. ทำให้เงื่อนไข SELECT แคบลง เช่น กรองด้วยวันที่/สถานะก่อน แล้วค่อยคำนวณ
4. ถ้าค่านี้ไม่จำเป็นต้องเรียลไทม์ พิจารณาเปลี่ยนเป็นคอลัมน์จริงที่ Action/Bot คำนวณเก็บให้ (ลดภาระตอน sync)
