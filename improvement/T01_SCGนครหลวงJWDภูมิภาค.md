## 📚 รายละเอียดปัญหาและวิธีแก้

### 1. 🟠 สูตรฝังตัวเลขคงที่ (ราคา/โบนัส/เกณฑ์) ไว้ข้างใน

**ตำแหน่ง:** คอลัมน์ `ผลการตรวจสอบงานส่ง`  
**ตัวเลขที่ฝังอยู่:** 100, 40, 60  

**ทำไมต้องแก้:** เมื่อราคาหรือเกณฑ์เปลี่ยน ต้องมาหาว่าสูตรไหนฝังเลขไว้บ้างแล้วแก้ทีละจุด เสี่ยงแก้ไม่ครบและแก้สูตรพลาดจนระบบคิดเงินผิด วิธีที่ยืดหยุ่นกว่าคือเก็บค่าเหล่านี้ไว้ในตารางตั้งค่า (เช่น Price_Table ที่แอปมีอยู่แล้ว) แล้วให้สูตรไปอ่านจากตาราง

**สูตร/ค่าปัจจุบัน:**
```
IFS( AND([ระยะขยับจากจุดเริ่มต้น_เมตร] <= 40, TOTALMINUTES([ระยะเวลาใช้งาน_นาที]) <= 10), "PASS", AND([ระยะขยับจากจุดเริ่มต้น_เมตร] <= 60, TOTALMINUTES([ระยะเวลาใช้งาน_นาที]) <= 15), "WARNING", OR([ระยะขยับจากจุดเริ่มต้น_เมตร] > 100, [ความเร็วการเคลื่อนที่_เมตร_นาที]> 60), "FAIL", TRUE, "WARNING" )
```

**วิธีแก้ใน AppSheet Editor:**

1. เพิ่มแถวค่าคงที่ลงตารางตั้งค่า/ตารางราคาที่มีอยู่ (เช่น Price_Table, PriceOverride) ให้ครบทุกเงื่อนไข
2. แก้สูตรให้ไป LOOKUP ค่าจากตารางแทนเลขที่ฝังไว้ เช่น `LOOKUP([ชื่องาน], "Price_Table", "งาน", "ราคา")`
3. หมายเหตุ: ถ้าเลขที่ฝังเป็นการแปลงหน่วย เช่น `* 1000` แปลงกิโลเมตรเป็นเมตร ไม่ต้องย้าย — นั่นคือคณิตศาสตร์ ไม่ใช่ค่าธุรกิจ

