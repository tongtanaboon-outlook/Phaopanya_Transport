# 🛠️ คู่มือปรับปรุง — T42 Process for สรุปส่วนต่าง - 1 Process Table

> **กลุ่ม:** 🤖 Process Table (สถานะการทำงานของ Bot) · ตารางระบบภายใน (ผู้ใช้ปกติมองไม่เห็น) · คอลัมน์ 12

## บทบาทของตารางนี้

AppSheet สร้างตารางนี้ให้อัตโนมัติเมื่อมีการสร้าง **Bot** เพื่อเก็บสถานะของแต่ละขั้นตอน (step) ว่ารันสำเร็จหรือไม่ คอลัมน์ `_ComputedKey_ID_*` คือสายพันธุ์ที่ชี้กลับไปยังแถวต้นทางในตารางข้อมูลจริง และคอลัมน์ Ref อื่น ๆ ชี้ไปยัง Output ของแต่ละ step

**Ref ไปยัง:** SCGนครหลวงJWDภูมิภาค, ทำเบิกส่วนต่างScgวังน้อย

## สิ่งที่ควรทำกับตารางนี้

1. **ห้ามแก้โครงสร้างเอง** — อย่าลบ/เปลี่ยนชื่อคอลัมน์ระบบ (เฉพาะ `_ComputedKey_ID_*` และคอลัมน์สถานะ step) จะทำให้ Bot พังทันที
2. **ตรวจว่า Bot ตัวนี้ยังใช้อยู่หรือไม่** — เปิด Automation > Bots ถ้าเลิกใช้แล้ว ลบ Bot ให้สะอาด ตาราง Process/Output จะไม่เกิดขึ้นใหม่
3. **ทำความสะอาดข้อมูลค้างเป็นระยะ** — ลบแถวที่เก่ากว่า 30–60 วันใน Google Sheets (ถ้าเป็น native table ให้ทำผ่านการรัน Bot ใหม่เท่านั้น) เพื่อไม่ให้ตารางบวม
4. **อย่าตั้ง Security Filter ที่รุนแรงกับตารางระบบ** — Bot อาจอ่านไม่เจอข้อมูลของผู้ใช้คนอื่นแล้วทำงานค้าง
