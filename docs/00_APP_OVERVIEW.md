## รูปแบบการควบคุมสิทธิ์ผู้ใช้

แอปนี้ใช้ระบบสิทธิ์ 2 ชั้นด้วยกัน ทำให้ผู้ใช้แต่ละคนเห็นและแก้ไขได้เฉพาะงานของตัวเอง ยกเว้นผู้ดูแลระบบ (ADMIN) ที่เห็นทุกอย่าง:

1. **Update mode ต่อตาราง** — กำหนดด้วยสูตร `SWITCH(USERROLE(), ...)` เช่น `=SWITCH(USERROLE(), "ADMIN", "ALL_CHANGES", "USER", "ADDS_AND_UPDATES", "READ_ONLY")` แปลว่า ADMIN ทำได้ทุกอย่าง USER เพิ่ม/แก้ได้แต่ลบไม่ได้ และบทบาทอื่นอ่านอย่างเดียว
2. **Security Filter ต่อตาราง** — กรองแถวข้อมูลตั้งแต่ระดับ data source เช่น `=OR(USERROLE() = "ADMIN", [Email พนักงาน] = USEREMAIL())` แปลว่าผู้ใช้ทั่วไปเห็นเฉพาะแถวที่อีเมลของตัวเองเป็นเจ้าของงาน

อีเมลพนักงานทั้งหมดในเอกสารนี้ถูกแทนที่ด้วย placeholder (`emp01@example.com` ฯลฯ) เพื่อความปลอดภัย ดูรายละเอียดที่ [SECURITY.md](../SECURITY.md)

## ข้อจำกัดสำคัญของเอกสารชุดนี้

- เอกสารต้นฉบับเป็น *สแนปช็อต* ณ วันที่สร้าง ไม่ได้อัปเดตตามที่แอปถูกแก้ไขภายหลัง
- นิยามของ Bot (เหตุการณ์ Event / ขั้นตอน Process / เงื่อนไข Trigger) **ไม่ถูก export มาในไฟล์ documentation** สิ่งที่เห็นได้คือ "ร่องรอย" ของ Bot ผ่านตาราง Process/Output ที่ AppSheet สร้างทิ้งไว้ ดู [06_BOTS_AND_PROCESS_TABLES.md](06_BOTS_AND_PROCESS_TABLES.md)
- ไม่มีข้อมูลแถวจริง (records) ในเอกสารนี้ — มีเฉพาะโครงสร้างและสูตร
- สูตรบางตัวอาจมีการเว้นวรรคเพี้ยนเล็กน้อยจากกระบวนการดึงข้อความจาก PDF แต่ความหมายของสูตรคงเดิม
